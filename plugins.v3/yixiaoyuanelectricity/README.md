# 易校园寝室电量

查询易校园 App 里绑定的寝室电费余额，企业微信里 `@` 机器人就能查；低于阈值时机器人主动在群里提醒。

官方易校园只有余额展示、没有低余额提醒，这个插件补的就是这块。

## 功能

- **手机号 + 短信验证码登录**易校园（只需一次，之后用 UID 自动续期会话）
- **企业微信智能机器人长连接**：不用公网 IP、不用域名、不用反向代理，机器人主动连出去
- 群里 `@机器人 查电量` 直接回余额
- **低于阈值自动提醒**：推到机器人所在的群（markdown）
- **使用人白名单**：只允许指定 userid 查询，别人 `@` 会被拒绝
- 配置页自带「发送验证码 / 登录」「测试机器人连接」「测试获取电量」「发一条测试提醒」四个按钮

## 前置条件

| 项 | 说明 |
|---|---|
| MoviePilot | V3（`>=3.0.0`） |
| 易校园账号 | 已在 App 里绑定「我的宿舍」，能自己看到电费 |
| 企业微信 | 自建应用或企业内部群；需要管理员权限创建「智能机器人」 |

## 使用步骤

### 1. 创建企业微信智能机器人

1. 企业微信管理后台 → **应用管理 → 智能机器人 → 创建机器人**
2. 模式选 **API 模式**，接入方式选 **长连接**
3. 复制 **BotID** 和 **Secret**
4. 把机器人**拉进群**（主动提醒只能发到群，单聊没有 chatid）

> 后台没有「智能机器人 / API 模式」的话，通常是企业微信版本旧或企业未认证，这条路走不通。

### 2. 插件里登录

配置页的「易校园登录」是三步式，验证码在自己的输入框里填：

1. 填**手机号** → 点右边的 **发送验证码**
2. 收到短信后，把 6 位数字填进 **「短信验证码（收到后填这里）」** 输入框
3. 点 **登录并绑定寝室** —— 成功会提示学校与寝室，插件自动记住 UID 和会话

验证码输入框是独立字段，而且**会跟着配置一起保存**，所以页面刷新或重新打开配置页时输入框不会丢值；`model.code` 一定存在，按钮不会把验证码传成 `undefined`。

**收不到短信 / 不想用短信**：填 UID（易校园抓包里的 `ymId`）→ 点 **用 UID 登录**，完全跳过验证码。UID 是本插件唯一必须的账号凭据，会话可以靠它无限续期。

验证码 5 分钟内有效；如果提示「验证码已过期」，重新点一次发送即可。

### 短信发太频繁会要求图形验证码

易校园对短信接口有风控：短时间内发太多次，`/common/security/token` 会返回 `level != 0`，此时必须同时提交图形验证码，否则会失败（前端可能只显示一句「请求参数不正确」）。

插件的处理方式：

1. 点 **发送验证码** 时先查 `level`，为 0 就直接发；
2. 非 0 时提示「易校园要求图形验证码」，并让你先点 **获取图形验证码**；图片会存到插件里，**把配置窗口关掉再重新打开**，图就直接显示在输入框上方（不再用新标签页打开图片地址，那条路在部分宿主版本会 404）；
3. 把图上的字符填进 **「图形验证码」** 输入框，再点 **发送验证码**，插件会把 `imageCaptchaValue` 一起提交；
4. 图形验证码和 `securityToken` 是一次性的，过期就再点一次「查看图形验证码」。

> 注意：图形验证码是**绑定在那一次 `securityToken` 上**的。插件现在会复用取图时的 token，不会在发短信时另换一个（换了服务端就报 `bizCode 10040 验证码错误`）。验证码用一次就作废，报 10040 时重新点「获取图形验证码」即可。

实在过不了风控（提示「触发号码天级流控」「请明天再来」），就别折腾短信了 —— 直接用下面的 **用 UID 登录**，完全不碰短信接口。

### 3. 填机器人参数并测试

1. 填 BotID / Secret
2. 点 **测试机器人连接**，应返回「机器人连接正常（订阅成功）」
3. 点 **测试获取电量**，应返回当前余额
4. 在群里 `@机器人 查电量`，让它把群会话 ID 记下来
5. 点 **发一条测试提醒到群**，确认主动推送可用

### 4. 设置提醒

- **低于多少提醒**：阈值，单位跟你的学校一致（有的学校按元，有的按度）
- **查询间隔（分钟）**：默认 30，学校电控一般 1 小时才同步一次，不用更频繁
- **单位**：留空自动判断（`isShowMoney=1` 就是元，`isShowSurplus=1` 就是度）
- **允许使用的人**：企业微信 userid，逗号分隔；留空表示所有人可用

最后打开 **启用插件** 并保存。

## 机器人支持的指令

| 指令 | 作用 |
|---|---|
| `@机器人 查电量` / `余额` / `还有多少钱` | 查当前余额 |
| `@机器人 阈值 30` | 改提醒阈值（会写回插件配置） |
| `@机器人 状态` | 看寝室、阈值、轮询间隔、学校 |
| `@机器人 帮助` | 指令表 |

## 实现说明

- 易校园接口：`queryBind`（bindType 依次试 3/1/2）+ `queryISIMSRoomSurplus` / `queryRoomSurplus` 兜底
- 会话：`unionid=UID → auth.xiaofubao.com/authoriz/getCodeV2 → shiroJID cookie`，过期自动续
- 企业微信：`wss://openws.work.weixin.qq.com`，`aibot_subscribe` 订阅，`aibot_respond_msg` 回复
- 回复用 `stream` 两帧，**必须等第一帧 ack 再发第二帧**，连发会被判版本冲突（errcode 6000）导致「一直转圈」
- 主动提醒用 `aibot_send_msg`，只支持 `markdown` 且必须带 `chatid`

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `登录失败：会话已过期；会话已过期` | 换取会话时服务端会连发三条 `shiroJID`（新的 → `deleteMe` → 最终可用），取错第一条就会 204 | 1.0.5 起改用 CookieJar 取最终值，升级后即可 |
| `发送失败：验证码错误（bizCode 10040）` | 图形验证码绑定的 `securityToken` 被换掉了 | 重新点「获取图形验证码」，5 分钟内发 |
| `短信发送失败：触发号码天级流控` | 号码被限流 | 改用「用 UID 登录」，不碰短信接口 |
| `846609 aibot websocket not subscribed` / 发消息没反应 | 同一个 bot 只允许一条长连接，早期「测试机器人连接」会另开一条把常驻顶掉 | 1.0.8 起测试不再新建连接，只复用常驻线程；收到 846609 自动重连 |
| `回包异常 846605: invalid req_id` | 回复帧没有回填回调里的 `req_id`（早期版本用了自动生成的 id） | 1.0.7 起回复帧严格回填回调 req_id，请升级 |

## 注意

- 插件不引入第三方依赖，AES 与 WebSocket 都是标准库实现
- 登录态（shiroJID）与 chatid 存在插件数据里，不写源码目录
- 禁用插件会停掉长连接线程
- 仅供查询自己账号的用电信息；请勿批量查询他人寝室
