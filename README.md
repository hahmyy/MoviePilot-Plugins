# MoviePilot Plugins

MoviePilot V3 插件仓库。

## 目录约定

- `plugins.v3/<plugin_id_lower>/`：V3 插件源码，主类位于 `__init__.py`
- `package.v3.json`：V3 插件市场元数据
- `tests/v3/<plugin_id_lower>/`：插件测试
- `docs/Plugin_Development.md`：插件开发主指南

新插件必须遵循 `docs/Plugin_Development.md`，使用 MoviePilot V3 稳定 SDK，并通过
版本检查、语法检查和相关测试后再发布。

## 当前状态

仓库已完成 V3 基础初始化，暂未添加具体插件。
